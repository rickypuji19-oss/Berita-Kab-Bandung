Cara sistem bekerja

1. Kumpulkan

RSS, API resmi, dan crawler yang memburu kata kunci seperti "Kabupaten Bandung", "Pemkab Bandung", dan nama pejabat.

2. Bersihkan

Hapus duplikat, saring berita di luar wilayah, dan beri bobot lebih pada media terverifikasi.

3. Nilai sentimen

Model bahasa Indonesia (IndoBERT) atau Claude API memberi label positif, netral, atau negatif dan menentukan topik.

4. Tampilkan

Hasil disimpan di database, dikirim lewat API, lalu digambar ulang di tata surya ini secara berkala.

Data di halaman ini adalah contoh ilustrasi, bukan hasil pengambilan berita sebenarnya. Untuk data nyata, tampilan ini perlu dihubungkan ke layanan yang mengumpulkan berita dan media sosial lalu menghitung sentimennya.
